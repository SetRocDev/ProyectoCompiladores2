BATERIA DE PRUEBAS - cada archivo de la carpeta 'casos' es una copia de CodigoProyecto.php con un
error provocado a proposito. La carpeta 'esperados' tiene el -errores.log exacto que debe generar cada caso.

Forma automatica (recomendada): ejecutar  pruebas\ejecutar-pruebas.bat  (doble clic en Windows)
    o  pruebas/ejecutar-pruebas.sh  (Linux / Git Bash). Compara cada .log con el esperado, byte por byte,
    y al final muestra cuantas pruebas pasaron y cuales fallaron.

Forma manual: copiar los archivos de 'casos' junto al .jar (carpeta dist), ejecutar
    java -jar ProyectoCompiladores2.jar
    y comparar los errores de cada nombre-errores.log con esta tabla.
